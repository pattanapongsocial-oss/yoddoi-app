# ยอดดอย — ติดตั้งเป็นแอปบนมือถือ (ไอคอนไม่มีตรา Chrome)

ชุดไฟล์นี้คือแดชบอร์ดตัวเดียวกับที่อยู่บนลิงก์ claude.ai แต่ทำเป็น **PWA** ที่เอาไปวางบนโฮสต์ของตัวเองได้
ข้อต่างสำคัญ 3 ข้อ:

- **ดึงราคาหุ้นจากตลาดได้จริง** เพราะอยู่บนโดเมนของเราเอง ไม่ติดข้อจำกัดแซนด์บ็อกซ์ของ claude.ai
- **เก็บข้อมูลไว้ในเครื่องที่เปิดเท่านั้น** (localStorage) ไม่ sync ข้ามเครื่อง
- **ไฟล์เริ่มต้นว่างเปล่า** ไม่มีตัวเลขการเงินของใครฝังอยู่ในไฟล์เลย (ดูหัวข้อความปลอดภัยด้านล่าง)

## ความปลอดภัย — อ่านก่อนอัปขึ้นเว็บ

เว็บที่โฮสต์บน GitHub Pages **ใครมีลิงก์ก็เปิดได้** แต่สิ่งที่เขาจะเห็นคือ *แดชบอร์ดเปล่า ๆ* เพราะ:

| | อยู่ที่ไหน | คนอื่นเห็นไหม |
|---|---|---|
| โค้ดหน้าเว็บ + รูปพื้นหลัง | ในไฟล์บน GitHub | เห็น (ไม่มีข้อมูลการเงิน) |
| เงินเดือน หนี้ พอร์ต รายการทั้งหมด | เบราว์เซอร์ในเครื่องคุณเท่านั้น | **ไม่เห็น** |
| สิ่งที่ส่งออกเน็ตตอนดึงราคา | ชื่อย่อหุ้น เช่น MU, IVV | ผู้ให้บริการราคาเห็นแค่ชื่อย่อ ไม่เห็นจำนวนหรือเงิน |

ข้อควรระวังที่เหลือ:

1. **อย่าอัปไฟล์ข้อมูลสำรอง (JSON) ขึ้น repo เด็ดขาด** — ไฟล์นั้นมีตัวเลขทั้งหมดของคุณ เก็บไว้ในเครื่องหรือใน Google Drive ส่วนตัวพอ
2. **ข้อมูลอยู่ในเครื่องเดียว** ล้างข้อมูลเบราว์เซอร์ ถอนแอป หรือเปลี่ยนเครื่อง = ข้อมูลหาย ให้กดสำรองข้อมูลเก็บไว้เดือนละครั้ง
3. **ใครหยิบมือถือที่ปลดล็อกแล้วไปเปิดก็เห็นข้อมูล** เหมือนแอปธนาคารทั่วไป — ล็อกหน้าจอมือถือไว้คือการป้องกันชั้นหลัก
4. อยากให้ลิงก์เปิดได้เฉพาะเรา ต้องมีระบบล็อกอินหน้าเว็บ ซึ่ง GitHub Pages ทำไม่ได้ (ต้องใช้ Cloudflare Pages + Cloudflare Access ซึ่งมีแพลนฟรีสำหรับผู้ใช้ไม่เกิน 50 คน) — แต่ถ้าไฟล์ไม่มีข้อมูลอยู่แล้ว การล็อกอินก็แทบไม่จำเป็น

ถ้าอยากให้ URL เดาไม่ถูกง่าย ๆ ตั้งชื่อ repo เป็นอะไรที่ไม่สื่อ เช่น `dashboard-x7k2` แทน `my-money` (ช่วยได้ระดับหนึ่ง แต่ไม่ใช่ระบบความปลอดภัยจริง)

## ไฟล์ในชุดนี้

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวแอปทั้งหมด (HTML + CSS + JS ในไฟล์เดียว) |
| `manifest.webmanifest` | บอก Chrome ว่าชื่อแอป ไอคอน สี และให้เปิดแบบเต็มจอ |
| `sw.js` | Service worker ทำให้เปิดใช้งานได้แม้ไม่มีเน็ต และเป็นเงื่อนไขที่ Chrome ต้องมีถึงจะยอมให้ "ติดตั้งแอป" |
| `icon-192.png`, `icon-512.png` | ไอคอนแอป (ยอดดอยสีเขียวมิ้นต์–ครีม บนพื้นเขียวหม่น) |
| `icon-maskable-192.png`, `icon-maskable-512.png` | ไอคอนแบบ maskable สำหรับ Android (กันโดนครอบตัดขอบ) |
| `apple-touch-icon.png`, `favicon.png` | ไอคอนสำหรับ iPhone/iPad และแท็บเบราว์เซอร์ |

ทั้งหมดต้องอยู่ **โฟลเดอร์เดียวกัน** และเปิดผ่าน **https** (หรือ localhost) เท่านั้น — เปิดจากไฟล์ในเครื่องตรง ๆ (file://) Chrome จะไม่ให้ติดตั้ง

## วิธีขึ้น GitHub Pages (ฟรี ใช้เวลาราว 5 นาที)

1. สมัคร/เข้า [github.com](https://github.com) แล้วกด **New repository**
   ตั้งชื่อเช่น `money` เลือก **Public** แล้วกด Create
2. ในหน้า repo กด **Add file → Upload files** แล้วลากไฟล์ทั้งหมดในโฟลเดอร์นี้เข้าไป (ลากทีเดียวทั้งหมดได้) กด **Commit changes**
3. ไปที่ **Settings → Pages** ตรง *Source* เลือก **Deploy from a branch**, Branch = `main`, folder = `/ (root)` แล้วกด **Save**
4. รอ 1–2 นาที หน้าเดิมจะขึ้นลิงก์ `https://<ชื่อบัญชี>.github.io/money/` — นั่นคือแอปของเรา

> โฮสต์อื่นที่ใช้ได้เหมือนกัน: Netlify Drop (ลากโฟลเดอร์ทิ้งใน netlify.com/drop), Cloudflare Pages, Vercel

## ติดตั้งลงหน้าจอหลัก (Android / Chrome)

1. เปิดลิงก์ที่ได้ด้วย **Chrome** บนมือถือ
2. ถ้ามีไอคอนเก่าที่เคยติดตั้งไว้ ให้ **กดค้าง → นำออก** ก่อน
3. เข้าแท็บ **ตั้งค่า** ในแอป (ไอคอนฟันเฟืองในแถบด้านล่าง) แล้วกดปุ่ม **ติดตั้งแอป** ที่การ์ดบนสุด (ถ้าปุ่มยังไม่ขึ้น ให้รีเฟรช 1 ครั้งแล้วรอสัก 3 วินาที)
4. กด **ติดตั้ง** ในกล่องยืนยันของ Chrome

**สาเหตุที่ไอคอนเดิมมีตรา Chrome ติดมุม** คือกด "เพิ่มลงในหน้าจอหลัก" ซึ่ง Android ถือว่าเป็น *ทางลัดเว็บ* จึงแปะตราเบราว์เซอร์ให้เสมอ
ต้องติดตั้งผ่าน **ติดตั้งแอป / Install app** เท่านั้น ไอคอนถึงจะเป็นของเราล้วน ๆ — ซึ่งจะขึ้นให้กดก็ต่อเมื่อไฟล์ครบ 3 อย่าง: https, `manifest.webmanifest` ที่มีไอคอน 192 + 512, และ service worker

### iPhone / iPad
Safari ยังไม่มีปุ่มติดตั้ง ให้กดปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม** ไอคอนจะใช้ `apple-touch-icon.png` และไม่มีตราเบราว์เซอร์อยู่แล้ว

## ใส่ข้อมูลครั้งแรก (ย้ายจากเวอร์ชันบน claude.ai)

1. เปิดแดชบอร์ดบน claude.ai → แท็บ **ตั้งค่า** → **สำรองข้อมูล (JSON)** → คัดลอกข้อความทั้งก้อน
2. เปิดแอปที่ติดตั้งใหม่ → **ตั้งค่า** → **นำเข้าข้อมูล** → วางแล้วกดนำเข้า

ทำย้อนกลับทางก็ได้เหมือนกัน และควรกดสำรองข้อมูลเก็บไว้เป็นระยะ เพราะเวอร์ชันติดตั้งนี้เก็บข้อมูลในเครื่อง ถ้าล้างข้อมูลเบราว์เซอร์หรือถอนแอปข้อมูลจะหายไปด้วย

## อัปเดตแอปทีหลัง

อัปโหลด `index.html` ทับของเดิมใน repo แล้วแก้เลข `CACHE` ใน `sw.js` (เช่น `yoddoi-v2` → `yoddoi-v3`) เพื่อบังคับให้เครื่องที่ติดตั้งไว้โหลดเวอร์ชันใหม่
